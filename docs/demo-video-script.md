# Demo video script (60 to 90 seconds)

**Setup:** two windows side by side: the website on the left (phone-width), the admin app on the right (desktop). Clear test data first. Use your own email for the booking so you can show the inbox. Record at 1080p; trim silences.

| Time | On screen | Voice-over (short, plain) |
|---|---|---|
| 0:00 | Website home | "This is a booking system I designed and built end to end: a public website and an admin app on one Supabase backend." |
| 0:08 | Services page, click Book this | "Services load straight from the database." |
| 0:14 | Booking step 2: pick a date and time | "Only genuinely free times appear, in South Africa time." |
| 0:24 | Step 3 details, Confirm | "The booking is saved in one step." |
| 0:30 | Admin app: new booking appears live | "In the admin app it appears instantly, no refresh." |
| 0:38 | Switch to inbox: client email and owner email | "Both the client and I get an email automatically." |
| 0:46 | Admin Calendar: tap the day, press Cancel | "From the calendar I can confirm or cancel. The client is emailed." |
| 0:55 | Website: try to book the same time in a second tab | "Double-booking is blocked by the database itself." |
| 1:03 | Admin: Time off, add a block, then website shows no times that day | "Blocking time off updates availability immediately." |
| 1:12 | Admin: Services, edit a price, reload website | "And I can change services and prices without touching code." |
| 1:20 | Architecture diagram | "Built with Figma, HTML and JavaScript, Flutter and Supabase. Code and write-up are linked below." |

**Tips:** keep your cursor slow and deliberate; zoom into the booking card and the email; no background music over the voice-over; add the live links in the video description.
